Premium NFT whitelist landing page for **THE MECHS** (1,777 unique MECHS).

## Live features

- X engagement tasks (Follow · Like · Repost · Tag 3 friends)
- Manual wallet + X username form (no wallet connection)
- Mint Date: TBA
- Submissions emailed to you via FormSubmit

## Important — set your email

Open `index.html` and replace this line:

```js
const RECEIVE_EMAIL = 'YOUR_EMAIL@example.com';
```

with your real email address.

**First submission:** FormSubmit will send a confirmation email to that address. Click the confirm link once. After that, every whitelist entry arrives in your inbox with X username + wallet address.

You can also export / view all submissions from the FormSubmit dashboard.
